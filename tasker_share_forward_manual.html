Tasker「共有(送る)テキスト転送先選択」タスク作成マニュアル

他アプリの「送る／共有」から受け取った文字列を、登録した複数のタスクの中から選んで転送する

目次

1. 概要 2. 事前準備 3. プロフィール作成 4. タスク作成 5. 転送先タスクでの受け取り 6. 動作確認 7. トラブルシューティング 8. カスタマイズ案

1. 概要

Androidの共有メニュー（他アプリの「送る」「共有」ボタン）からTaskerを選ぶと、 共有された文字列を受け取り、あらかじめ登録しておいた転送先タスクの一覧を ダイアログで表示します。ユーザーが一覧からタスクを選ぶと、共有された文字列を パラメータ（%par1）として渡してそのタスクを実行します。

全体の流れ
他アプリで「共有」→ Taskerを選択 → プロフィールが発火 → 共有テキストを取得 → 転送先タスクの選択ダイアログを表示 → 選ばれたタスクを、共有テキストを引数にして実行

2. 事前準備

  • Tasker アプリ（Google Play版、v5.9以降推奨。List Dialog アクションを使うため）
  • 転送先にしたいタスクをあらかじめ作成しておく（例：「メモに追記」「翻訳する」「URLをブラウザで開く」など）
  • Android設定で Tasker に対して以下を許可しておく
  • 他のアプリの上に表示（ダイアログ表示に必要）
  • バッテリー最適化の除外（バックグラウンドから起動された際にキルされないため）
これらの権限が無いと、共有直後にTaskerがバックグラウンドで止められ、選択ダイアログが出ないことがあります。

3. プロフィール作成（共有を受け取る入り口）

  1. Taskerで プロフィール タブ → + → イベント
  2. システム → インテントを受信（Intent Received）を選択
  3. 以下のように設定する
項目設定値
Actionandroid.intent.action.SEND
Cat空欄のままでOK（アプリによってDEFAULTが付かない場合があるため）
Mime Typetext/*

この後、紐づけるタスクの選択画面が出るので、次の章で作る新規タスクを割り当てます。

「Intent Received」で登録すると、他アプリの共有メニューに「Tasker」が候補として表示されるようになります。

4. タスク作成（共有先選択）

タスク名は例として 「共有先選択」 とします。以下のアクションを順番に追加します。

  1. 変数設定：共有テキストを取得
    タスク → 変数 → 変数設定
    名前: %SharedText　値: %aextra_android_intent_extra_text
  2. （任意）件名のみ共有された場合のフォールバック
    If %SharedText !Set
    → 変数設定 %SharedText = %aextra_android_intent_extra_subject
    End If
  3. 転送先タスク一覧を定義
    変数設定 名前: %FWD_TASK_LIST　値: 転送先タスク名をカンマ区切りで列挙
    例: メモに追記,翻訳する,URLを開く
    ※ここに書くタスク名は、Tasker上に実在するタスク名と完全一致させること
  4. カンマ区切りを配列に分割
    タスク → 変数 → 変数分割（Variable Split）
    名前: %FWD_TASK_LIST　区切り文字: ,
  5. 選択ダイアログを表示
    タスク → アラート → リストダイアログ（List Dialog）
    タイトル: 転送先を選択　項目: %FWD_TASK_LIST()（配列全体を渡す）
    出力変数: %SelectedTask
  6. 選択されたタスクを実行
    If %SelectedTask Set
    → タスク → タスク実行（Perform Task）
    　名前: %SelectedTask　パラメータ1: %SharedText
    End If
ポイント：リストダイアログでキャンセルされた場合は %SelectedTask が未設定のままなので、 If で分岐させることで何も実行せず終了できます。

5. 転送先タスクでの受け取り方

「共有先選択」から呼び出される各転送先タスク（例：「メモに追記」）の 先頭アクションで、渡された文字列を受け取ります。

変数設定 名前: %ReceivedText　値: %par1

以降のアクションでは %ReceivedText（または直接 %par1）を使って処理を組み立てます。

6. 動作確認

  1. ブラウザやメモアプリなどで適当な文字列を選択・共有
  2. 共有先アプリ一覧から「Tasker」を選ぶ（確認のため「1回のみ」を選択しておくと切り替えやすい）
  3. 「転送先を選択」ダイアログが表示されることを確認
  4. 一覧からタスクを選び、そのタスクが共有テキストを受け取って正しく動作するか確認

7. トラブルシューティング

症状対処
共有メニューにTaskerが出てこない プロフィールのMime Typeが text/* になっているか確認。プロフィールが有効（緑）になっているか確認
選択ダイアログが表示されない／一瞬で消える 「他のアプリの上に表示」権限とバッテリー最適化除外を確認
%SharedText が空になる 共有元アプリによっては extra キー名が異なる場合があるため、変数設定の直後に フラッシュ（Flash）アクションで %SharedText の中身を表示して確認する
Perform Taskでタスクが見つからないと言われる %FWD_TASK_LIST に書いたタスク名とTasker上の実際のタスク名が 一字一句一致しているか確認（全角/半角・スペースに注意）

8. カスタマイズ案

  • %FWD_TASK_LIST を独立した「設定」タスクやシーンで編集できるようにし、 転送先タスクを追加・削除しやすくする
  • 選択後にトースト通知（Flash）で「〇〇に転送しました」と表示する
  • よく使う転送先を先頭に来るよう並び替える
  • 特定のアプリから共有された場合だけプロフィールを発火させたい場合は、 Intent Received の パッケージ欄で送信元アプリを絞り込む
