1Wrench（レンチ）

機械を回転・調整する基本工具

📝 説明

WrenチはCreateモッドの基本となる工具です。機械ブロックを回転させたり、回転方向を変更したりできます。

🎯 使い方

  • 機械ブロックを右クリックして回転方向を変更
  • Shiftを押しながら右クリックで機械の回転速度を確認
  • 空中で右クリックするとWrenchが回転
使用例: Shaft（シャフト）の回転方向を変えたい場合、Wrenチで直接クリックして方向を設定できます。
Wrenチは無限に使用でき、耐久度がありません。複数個所の機械を素早く調整できます。

2Mechanical Press（機械プレス）

アイテムを圧縮・成形する重要な機械

📝 説明

回転動力を受け取り、上から下に押し下げる動作でアイテムを加工します。鉱石の圧縮、インゴットの成形など多くのレシピに対応。

🎯 使い方

  • Shaftで回転動力を供給（下または横から接続可能）
  • 上部にアイテムを投入（ホッパーなどで自動化可能）
  • 加工後のアイテムは下に落ちる
  • 複数のPressを縦に重ねることで連続加工も可能

⚙️ 必要な回転速度

通常のレシピ: 32 RPM以上推奨

使用例: 鉄鉱石をプレスして鉄粉に加工し、さらに別のプレスで圧縮してダイヤモンドを生成。
複数のプレスを組み合わせることで複雑なアイテム加工パイプラインを構築できます。

3Mechanical Mixer（機械ミキサー）

複数のアイテムを混ぜ合わせる機械

📝 説明

回転動力を受け取り、タンク内のアイテムと液体を混ぜてクラフトします。粘土や洗浄バッグなど、複数材料の加工に使用。

🎯 使い方

  • Shaftで回転動力を供給（横から接続）
  • 必要な材料をタンクに投入
  • 適切な回転が行われると自動的に混合開始
  • 完成したアイテムは下のホッパーに流出

⚙️ 必要な回転速度

通常のレシピ: 24 RPM以上推奨

使用例: 洗った鉱石粉とセメントダストを混ぜて、セメント粉を生成。
タンク内の液体がオーバーフローしないよう注意してください。

4Goggles（ゴーグル）

機械の情報を表示する装備品

📝 説明

頭部に装備するアイテムで、Createの機械ブロックを見るときに詳細な情報が表示されます。.

🎯 使い方

  • インベントリから頭部スロットに装備
  • 装備後、機械ブロックを見ると回転速度などの情報が表示
  • スニークしながら見ると、さらに詳細な情報が表示

📊 表示される情報

  • 回転速度 (RPM) - 機械の回転速度
  • 応力 (Stress) - 現在の負荷状態
  • 回転方向 - 時計回りまたは反時計回り
  • 状態 - 動作中か停止中か
Goggleを装備することで、機械システムの問題箇所を素早く発見できます。

5Gearbox（ギアボックス）

回転動力の方向を変更する機械

📝 説明

複数の方向から回転動力を受け取り、別の方向に動力を転送できます。複雑な機械配置に必須のパーツ。

🎯 使い方

  • Shaftを6面全てに接続可能
  • 一つの面から受け取った動力を他の面に転送
  • 複数の動力ソースを組み合わせることも可能
  • Wrenchiで接続面を指定
使用例: 風車の上下動力を横方向に変更して、離れた場所の機械を動かす。
Gearboxは動力の転送のみで、速度比は変わりません（1:1）。速度変更にはOther gearboxesを使用してください。

6Mechanical Drill（機械ドリル）

回転動力で鉱石を自動採掘する機械

📝 説明

回転動力を受けると、その前方のブロックを掘削して鉱石を採集します。採掘スピードはRPMに依存。

🎯 使い方

  • Shaftで回転動力を供給（上下どちらでも可）
  • ドリルの向いている方向の鉱石を自動採掘
  • 採掘速度 = RPM / 100 ブロック/秒
  • 採掘されたアイテムは下方向に落ちる

⚙️ 必要な回転速度

採掘速度向上: RPM が高いほど高速

使用例: 64 RPMで動作させると、毎秒0.64ブロックの速度で採掘開始。
ドリルの前のブロックが固い場合、採掘にかかる時間が増加します。

7Deployer（デプロイヤー）

アイテムを配置・適用する多目的機械

📝 説明

回転動力を受け取り、インベントリ内のアイテムを世界に配置したり、他のアイテムに適用したりできます。

🎯 使い方

  • Shaftで回転動力を供給（あらゆる方向から可能）
  • 内部にホッパーでアイテムを投入
  • 回転状態が続く間、アイテムを繰り返し適用
  • 配置方向を変更可能（Wrenchiで調整）

📋 Deployerの用途

  • オブザーバー付きチェスト: ペイント塗布
  • 耕地: 耕すまたは種まき
  • ブロック: 配置
複数のDeployerを組み合わせることで、複雑な自動化パイプラインを構築できます。

8Sequenced Gearshift（シーケンスギアシフト）

複雑な制御を実現する高度な機械

📝 説明

特定の条件に基づいて、回転動力の供給をコントロールできる高度な機械。複雑な自動化パイプラインに必須。

🎯 使い方

  • Shaftで回転動力を供給
  • GUI で複数のシーケンス条件を設定
  • 条件が満たされている時のみ、指定方向に動力を転送
  • 複数の条件を組み合わせて順序制御が可能

⚙️ 設定可能な条件

  • タイマー条件 - 指定時間が経過したか
  • 信号強度 - レッドストーン信号の強度
  • インベントリ条件 - 特定のアイテムが存在するか
複雑な設定が必要なため、初心者向けではありません。まず基本的な機械システムを理解してから使用してください。

9Mechanical Saw（機械ノコギリ）

回転動力で木材やブロックを切断加工する機械

📝 説明

回転する円形のノコギリでアイテムやブロックを切断します。原木を板に加工したり、複数に分割したりできます。

🎯 使い方

  • Shaftで回転動力を供給（上下どちらでも可）
  • ノコギリの前後にホッパーを配置
  • 切断対象のアイテムを自動投入
  • 一定回転で切断動作を実行

⚙️ 切断可能なアイテム

  • 原木 → 木の板
  • 石 → 石の煉瓦
  • 砂岩 → 砂岩の煉瓦
  • その他のカスタムレシピ
使用例: 大量の原木を自動で木の板に加工し、エネルギー源として活用。
Mechanical Sawはプレスと異なり、横方向の配置でも動作します。

10Mechanical Bearing（機械ベアリング）

ブロックを回転させる動力伝達部品

📝 説明

回転動力を受け取り、その上に乗ったブロックを回転させます。水車や独特な構造物を作成するのに活用。

🎯 使い方

  • Shaftで回転動力を供給（上から接続）
  • Bearingの上にブロックを配置
  • 配置されたブロックが回転開始
  • 回転ブロック上に他のブロックを積む場合、Superglueで接着

📋 活用例

  • 水車 - 見た目の良いエネルギー生成装置
  • 装飾 - 回転する柱や球体
  • アイテム搬送 - 回転するコンベヤー
使用例: Windmill Bearingとビーム材を組み合わせて、風力発電装置を構築。
Superglueというアイテムを使用することで、複雑な回転構造も実現可能です。
