# タッチジェスチャー: 1本指でL字を描いてタブを閉じる

ページ上で **1本の指でL字（直角に近い2辺からなる軌跡）を描く** と、アクティブなタブを閉じるジェスチャーです。L字は上下左右どの向き（L・Γ・J・⌐相当）でも認識します。通常のスクロールと衝突しないよう、指を動かしている間はページのデフォルト動作（スクロール）を妨げません。

## ⚠️ Edge for Android へのインストールについて（重要）

調べた結果、Edge for Android の**安定版**（例: バージョン 150.x）には、独自の拡張機能をサイドロードする仕組み自体がありません。安定版にあるのは Microsoft が審査・承認した一部の拡張機能だけを選べる「拡張機能ストア」のみです。ローカルフォルダの読み込みは **Edge Canary** にしかなく、しかもそれは「Microsoft Edge Add-ons ストアに公開済みの拡張機能を ID 指定でインストールする」方式で、デスクトップのような「フォルダを直接読み込む」機能はありません。

そのため、このリポジトリには2つの実装を用意しています。

| 方式 | ファイル | 安定版Edgeで今すぐ使えるか |
|---|---|---|
| **Tampermonkeyユーザースクリプト（推奨）** | `tab-close-gesture.user.js` | ○ Tampermonkey自体が拡張機能ストアの承認済みアプリなので、安定版でも今すぐ使えます |
| Chromium拡張機能（Manifest V3） | `manifest.json` ほか | △ 現状Edge Canaryでの公開拡張機能ID経由、またはデスクトップ版Edge/Chromeでのみ利用可 |

## Tampermonkeyユーザースクリプトのインストール手順（推奨）

1. Edge for Android の「拡張機能」ストアから **Tampermonkey** をインストールする（メニュー → 拡張機能 → 追加できる拡張機能一覧から選択）。
2. Tampermonkey を開き、「ユーザースクリプトを作成」または「ダッシュボード」→「ユーティリティ」→「インポート」などから `tab-close-gesture.user.js` の中身を貼り付けて保存する。
   - GitHub上のraw URLを開くと、Tampermonkeyが自動的にインストール画面を表示することもあります。
3. 保存後、対象のWebページ上で1本指でL字（例: 下に指を動かしてから右に曲げる）を描くと、タブが閉じます。
4. ON/OFFはTampermonkeyのメニュー（ブラウザメニュー内のTampermonkeyアイコン、または拡張機能アイコンをタップ）から「ジェスチャーを無効にする/有効にする」で切り替えられます。

## Chromium拡張機能（Manifest V3）版について

こちらは通常の `chrome.tabs` APIを使った実装で、デスクトップ版Edge/Chromeでの動作確認や、将来的にEdge Add-onsストアへ公開する場合のベースとして残しています。現時点のEdge for Android安定版では利用できません。

## 仕組み（Chromium拡張機能版）

- `content.js`: 各ページに挿入され、`touchstart`/`touchmove`/`touchend` を監視。1本指の軌跡を記録し、2000ms以内に完了かつ各辺70px以上・直交する2辺（L字）とみなせる場合にジェスチャーとして認識し、`background.js` にメッセージを送る。角の検出は始点・終点を結ぶ直線から最も離れた点を「曲がり角」とみなす方式。
- `background.js`: メッセージを受け取り `chrome.tabs.remove()` でタブを閉じる（`tabs` 権限が必要なため content script からは直接呼べない）。
- `popup.html`/`popup.js`: `chrome.storage.sync` に有効/無効を保存する簡易設定画面。

## Edge for Android へのインストール（サイドロード）

Edge for Android は2025年以降、開発者向けの拡張機能サイドロードに対応しています。

1. Edge for Android を開き、右下のメニュー（`…`）→ **設定** → **Microsoft Edge について** をタップ。
2. バージョン表示部分（例: 「Edge Canary バージョン」等の表記）を連続で5回タップし、開発者オプションを有効化する。
3. 設定内に追加された **拡張機能** メニューを開き、ローカルの拡張機能を読み込む操作（フォルダ選択 / zip アップロード等、バージョンにより異なる）を選ぶ。
4. この `edge-touch-gesture-extension` フォルダ一式（または zip 化したもの）を選択してインストールする。

※ サイドロード機能はまだ展開中のベータ機能のため、Edge のバージョンによりメニュー名や手順が異なる場合があります。うまく見つからない場合は、まず Edge を最新版に更新してください。

## デスクトップ版 Edge / Chrome での動作確認

タッチイベントを使うため実機（またはタッチエミュレーション有効な DevTools）が必要です。

1. `edge://extensions`（Chrome の場合は `chrome://extensions`）を開く。
2. 「開発者モード」を ON にする。
3. 「展開して読み込み」からこのフォルダを選択する。
4. DevTools のデバイスツールバー（タッチエミュレーション）を有効にしたページで、L字ドラッグに相当する操作を試す。

## 注意事項

- スクロールを妨げないよう `touchmove` で `preventDefault()` を呼んでいません。そのため通常のスクロール中に偶然L字に近い軌跡（例: 縦にスクロールしてから横にスクロール）を描くと、意図せずタブが閉じる可能性があります。気になる場合はポップアップ（拡張機能版）やTampermonkeyメニュー（ユーザースクリプト版）から一時的に無効化してください。
- 各辺70px未満、直交度が緩い（軸に対して斜めすぎる）、軌跡が波打っていて直線から大きく外れている、2000msを超えて描いた場合は認識されません。
- 最後の1枚のタブなど、ブラウザ側の制約でタブを閉じられない場合は何も起きません。
